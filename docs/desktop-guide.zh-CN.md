# WebCodex Desktop 使用指南

[English](desktop-guide.md) | [简体中文](desktop-guide.zh-CN.md)

Desktop 负责准备本机项目和管理连接；你在 ChatGPT 等 AI 客户端中发起工作。首次安装、Tunnel 环境变量和系统权限请看[安装与连接指南](desktop-install.zh-CN.md)。

## 第一次使用

1. 在欢迎页选择 **在此电脑使用 WebCodex**。这是普通个人使用的推荐入口。
2. 点击 **选择文件夹**，选择真正要交给 AI 使用的项目。页面首先展示项目路径；确认无误后点击 **配置 WebCodex**。
3. Tunnel 配置检测位于 **可选：检查 ChatGPT 安全隧道配置** 中。没有 Tunnel 配置也可以先准备本机项目；配置齐全时，可勾选配置后连接 ChatGPT。
4. 回到首页，确认当前项目路径与实际工作目录一致。首页的三个步骤依次是 **准备项目 → 连接 AI 客户端 → 开始使用**。
5. 点击 **打开连接设置**。选择 **OpenAI Secure Tunnel** 后，再点击 **启动安全隧道**。仅选择连接方式不会启动进程。
6. 隧道就绪后，按照连接页指引在 ChatGPT 中填入 Tunnel ID，再执行一次真实项目读取。

**本地隧道就绪不等于 ChatGPT 已连接。** 首页会保留等待验证的状态；只有观察到当前项目的真实调用，才显示使用已验证。

如果已有远程 Server，欢迎页选择 **连接现有 Server**，填写地址和配对码，再选择本机项目。Desktop 连接页会显示远程 Server 信息，外部连接由 Server 管理者负责。

如果只想临时使用一个项目，选择 **快速共享项目**，再选择连接提供方。Quick Share 是独立的临时使用方式；首页提供连接交接信息和停止入口。

## 每天从首页开始

首页优先显示整体状态、下一步操作和当前工作项目。运行环境停止时可点击 **恢复运行环境**；本机项目已就绪且 Tunnel 配置齐全时可点击 **启动安全隧道**。

- **当前工作项目**：展示项目名和完整路径。点击 **选择其他项目** 进入配置；进入配置本身不会修改运行环境，点击应用后才生效。
- **三个步骤**：区分项目就绪、连接准备和实际使用验证，帮助判断还缺哪一步。
- **查看运行诊断**：按需展开 Service、Runner、项目和连接的详细状态。
- **查看项目 / 管理连接 / 查看活动**：进入对应页面处理具体事项。

切换项目无需先手工停止 Runtime。Desktop 会保留自己管理的 Service，必要时替换自己的 Runner，并重新确认所选项目就绪。不要通过扩大允许目录来解决项目加载失败。

## 连接与故障恢复

连接页先展示当前状态和可执行操作，下方提供 ChatGPT 连接步骤。配置缺失时，Tunnel 配置检测自动展开；这里仅显示配置是否存在，不展示 API key。

| 看到的情况 | 下一步 |
| --- | --- |
| 本机运行环境未就绪 | 回首页恢复运行环境；需要时重新配置同一个项目 |
| Tunnel ID 或 API key 未检测到 | 按安装指南配置环境，完全退出后重开 Desktop，再重新检测 |
| 启动失败且没有活动隧道 | 保留当前选择，修复配置或网络后再次点击启动 |
| 已有隧道报错 | 点击停止，成功后重新启动；停止失败会保留错误和重试入口 |
| 隧道就绪但剪贴板交接失败 | 恢复剪贴板权限，停止并重启隧道 |
| 隧道就绪，等待 ChatGPT | 在 ChatGPT 配置 Tunnel，并读取所选项目的 README |

**设置 → OpenAI Tunnel 网络** 管理自动、直连和自定义 HTTP 代理。更改运行中隧道的代理前先停止隧道，保存后再启动。

## 活动、设置和后台运行

**活动** 按最新在前显示操作记录。可搜索内容或来源，也可选择 **只看警告和错误**；筛选不会删除记录。

**设置** 包含语言、登录时启动、Tunnel 网络和诊断信息。语言也可以在左下角直接切换。

关闭窗口只是隐藏到菜单栏或系统托盘，已启动的运行环境仍在后台工作。托盘中的 **退出 WebCodex** 才会结束 Desktop 及其管理的进程。首页的 **停止 Desktop 管理的运行环境** 会停止运行环境并更新保存的启动偏好；这些操作不会终止其他自行启动的 WebCodex 进程。

macOS 使用 **⌘ + 1–5**，Windows 使用 **Ctrl + 1–5** 切换五个页面。输入框内不接管这些快捷键。可用 Tab 聚焦按钮，用 Enter 激活；诊断折叠项也支持键盘操作。
